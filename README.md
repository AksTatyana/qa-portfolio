## 1. Чек-лист: Корзина (Saucedemo)

**Проект:** https://www.saucedemo.com  
**Функция:** Корзина  
**Цель:** Проверить корректность работы корзины.

- [ ] Добавление товара в корзину с главной страницы
- [ ] Добавление товара в корзину со страницы товара
- [ ] Удаление товара из корзины
- [ ] Обновление счётчика корзины при добавлении/удалении
- [ ] Отображение товаров в корзине (название, цена, фото)
- [ ] Поле количества товара (должно быть редактируемым)
- [ ] Переход в корзину по иконке корзины
- [ ] Переход на главную страницу из корзины (Continue Shopping)
- [ ] Переход к оформлению заказа (Checkout)
- [ ] Ссылки соцсетей из корзины

## 3. Баг-репорты

### Баг-репорт №1: Стрелка фильтра не реагирует

**Название:** Стрелка выпадающего списка фильтра не реагирует на клик  
**Серьёзность:** Major  
**Приоритет:** Medium  

**Шаги:**  
1. Открыть главную страницу saucedemo.com  
2. Нажать на стрелку (▼) в поле фильтра  

**Фактический результат:** Клик не работает, список не открывается  
**Ожидаемый результат:** Открывается список фильтров  
**Окружение:** Chrome, Windows  
**Статус:** New

### Баг-репорт №2: Ссылки соцсетей открываются в той же вкладке

**Название:** Ссылки соцсетей открываются в той же вкладке  
**Серьёзность:** Major  
**Приоритет:** Medium  

**Шаги:**  
1. Добавить товар в корзину  
2. Пролистать вниз  
3. Нажать иконку Twitter  

**Фактический результат:** Ссылка открывается в той же вкладке, корзина теряется  
**Ожидаемый результат:** Открывается в новой вкладке  
**Окружение:** Chrome 134, Windows 11  
**Статус:** New

### Баг-репорт №3: Поле количества товара недоступно

**Название:** Поле количества товара в корзине недоступно для редактирования  
**Серьёзность:** Minor  
**Приоритет:** Medium  

**Шаги:**  
1. Открыть корзину  
2. Попытаться изменить количество товара  

**Фактический результат:** Поле неактивно  
**Ожидаемый результат:** Поле редактируемое  
**Окружение:** Chrome 134, Windows 11  
**Статус:** New
